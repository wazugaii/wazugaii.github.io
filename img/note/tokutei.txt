<p>証券口座を開くときに出てくる「特定口座（源泉徴収あり）」「特定口座（源泉徴収なし）」「一般口座」。何がちがうのか、ポイントごとに整理します。</p>
<p>※ 2026年11月時点の一般的な制度の説明です。どれを選ぶべきかは、人によって違います。この記事は特定の金融機関や商品をすすめるものではありません。</p>
<h2>1. そもそも、なぜ口座の種類があるの？</h2>
<ul>
<li>NISA 以外で株や投資信託を売って利益が出ると、<strong>約20%（20.315%）の税金</strong>がかかる</li>
<li>この税金の計算や支払いを、<strong>誰がどこまでやるか</strong>で口座の種類が分かれている</li>
<li>NISA 口座で出た利益には、この税金はかからない</li>
</ul>
<h2>2. 3つの口座のちがい</h2>
<p><strong>特定口座（源泉徴収あり）</strong></p>
<ul>
<li>金融機関が税金を計算して、<strong>利益から先に差し引いて</strong>納めてくれる</li>
<li>ふつうは<strong>確定申告がいらない</strong></li>
</ul>
<p><strong>特定口座（源泉徴収なし）</strong></p>
<ul>
<li>金融機関が1年分の利益をまとめた書類（年間取引報告書）を作ってくれる</li>
<li>税金は、その書類をもとに<strong>自分で確定申告</strong>して納める</li>
</ul>
<p><strong>一般口座</strong></p>
<ul>
<li>計算も申告も、<strong>すべて自分で</strong>する</li>
</ul>
<h2>3. 「源泉徴収なし」だと、申告がいらないこともある</h2>
<ul>
<li>会社員などで、給料以外の所得（株の利益など）が<strong>年20万円以下</strong>なら、所得税の確定申告はいらないことがある</li>
<li>ただし、<strong>住民税の申告</strong>は必要</li>
<li>
<p>ほかに確定申告をする場合（医療費控除など）は、株の利益もあわせて書く必要がある</p>
</li>
<li>

</li>
<li><a href="https://note.com/fresh_snake1249/n/n065312686d06">会社員でも確定申告が必要な人・したほうが得な人チェックリスト</a></li>
</ul>
<h2>4. 損をしたときは？</h2>
<ul>
<li>同じ年の、ほかの特定口座の利益と<strong>相殺（損益通算）</strong>できる</li>
<li>確定申告をすれば、損を<strong>3年間繰り越せる</strong></li>
<li>
<p>NISA の損は、相殺も繰り越しもできない</p>
</li>
<li>
<p><a href="https://note.com/fresh_snake1249/n/nd41d6e88bb7e">NISAで損をしたらどうなる？</a></p>
</li>
</ul>
<h2>5. あとから変えられる？</h2>
<ul>
<li>「源泉徴収あり・なし」は、<strong>その年の最初の売却（や配当の受け取り）の前まで</strong>なら変えられることが多い</li>
<li>年の途中で一度売ったあとは、<strong>翌年から</strong>の変更になる</li>
<li>くわしい締め切りは、利用している金融機関で確認しましょう</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>源泉徴収あり：税金を金融機関が差し引いて納めてくれる。ふつうは確定申告がいらない</li>
<li>源泉徴収なし：書類は作ってくれるが、申告は自分で。会社員で利益が年20万円以下なら所得税の申告がいらないことも（住民税の申告は必要）</li>
<li>一般口座：計算も申告も自分で</li>
<li>変更は、その年の最初の売却の前まで。NISA の利益はそもそも非課税</li>
</ul>
