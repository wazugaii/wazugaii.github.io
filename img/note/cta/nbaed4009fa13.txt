<p>年末から1月にかけて会社からもらう「源泉徴収票」。小さい字で数字がたくさん並んでいて、どこを見ればいいかわからない人も多いと思います。</p>
<p>この記事では、<strong>まず見てほしい4つの数字</strong>と、それぞれの使い道をまとめます。</p>
<p>※ 一般的な会社員の源泉徴収票の説明です。</p>
<h2>1. 源泉徴収票とは</h2>
<p>1年間（1月〜12月）に会社から受け取った給料と、引かれた所得税の<strong>1年分の記録</strong>です。年末調整が終わったあと、12月〜1月ごろに会社からもらいます。</p>
<p>使う場面：</p>
<ul>
<li>確定申告をするとき（医療費控除・ふるさと納税・副業など）</li>
<li>ふるさと納税の上限を計算するとき</li>
<li>転職するとき（新しい会社に出す）</li>
<li>ローンを組むとき・保育園の申し込みなど、収入の証明に</li>
</ul>
<h2>2. まず見てほしい4つの数字</h2>
<p><strong>① 支払金額（いわゆる「年収」）</strong></p>
<ul>
<li>1年間の給料・ボーナスの合計（税金などが引かれる前の額面）</li>
<li>通勤手当（非課税の分）は含まれない</li>
</ul>
<p><strong>② 給与所得控除後の金額（いわゆる「所得」）</strong></p>
<ul>
<li>支払金額から「給与所得控除」を引いた金額</li>
<li>2026年分は、給与所得控除の最低額が74万円（所得税）になっている</li>
</ul>
<p><strong>③ 所得控除の額の合計額</strong></p>
<ul>
<li>社会保険料控除・基礎控除・生命保険料控除・扶養控除など、所得から引ける控除の合計</li>
</ul>
<p><strong>④ 源泉徴収税額（1年間の所得税）</strong></p>
<ul>
<li>年末調整のあとの、1年分の所得税（復興特別所得税を含む）</li>
<li>これが<strong>0円</strong>なら、所得税はかかっていない</li>
</ul>
<p><strong>ざっくり言うと</strong></p>
<p>④ の所得税は、（② − ③）× 税率 で計算されています。</p>
<h2>3. ほかの欄も見ておくと便利</h2>
<ul>
<li><strong>社会保険料等の金額</strong>：1年間に給料から引かれた健康保険・厚生年金・雇用保険などの合計</li>
<li><strong>生命保険料の控除額・地震保険料の控除額</strong>：年末調整で申告した保険の控除</li>
<li><strong>住宅借入金等特別控除の額</strong>：住宅ローン控除の額</li>
<li><strong>控除対象扶養親族の数</strong>：年末調整で申告した扶養家族</li>
</ul>
<h2>4. 2026年分で変わったところ</h2>
<p>2026年分は「178万円の壁」で、</p>
<ul>
<li>基礎控除が増えた（所得489万円以下の人は104万円）</li>
<li>給与所得控除の最低額が74万円に上がった</li>
</ul>
<p>ため、多くの人は<strong>④ 源泉徴収税額が去年より少なく</strong>なっています。去年の源泉徴収票と比べてみると、どれくらい減ったかがわかります。</p>

<h2>5. ふるさと納税の上限を確かめるときは</h2>
<p>源泉徴収票の <strong>① 支払金額</strong> と家族構成を入れると、ふるさと納税の上限の目安が計算できます。来年の寄附の目安にもなります。</p>

<h2>6. なくしたら？</h2>
<p>会社に頼めば再発行してもらえます。転職した場合は、前の会社に頼みます。</p>
<h2>まとめ</h2>
<ul>
<li>源泉徴収票は、1年間の給料と所得税の記録</li>
<li>まず見るのは「支払金額」「給与所得控除後の金額」「所得控除の額の合計額」「源泉徴収税額」の4つ</li>
<li>2026年分は基礎控除などが増えたので、源泉徴収税額が去年より少ない人が多い</li>
<li>確定申告・ふるさと納税・転職・収入の証明に使うので、なくさず保管</li>
</ul>
