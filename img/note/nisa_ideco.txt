<p>「NISA と iDeCo、どっちも税金が得になるらしいけど、何がちがうの？」という疑問を、表にせず、ポイントごとに比べて整理します。</p>
<p>※ 2026年10月時点の一般的な制度の説明です。どちらを使うべきか、いくら積み立てるべきかは、人によって違います。この記事は特定の商品やサービスをすすめるものではありません。</p>
<h2>1. ひとことで言うと</h2>
<ul>
<li><strong>NISA</strong>：運用で増えた分（利益）に税金がかからない。<strong>いつでも引き出せる</strong></li>
<li><strong>iDeCo</strong>：払った掛金が<strong>所得控除</strong>になり、毎年の税金が減る。運用益も非課税。ただし<strong>原則60歳まで引き出せない</strong></li>
</ul>
<h2>2. 税金の得のしかたのちがい</h2>
<p><strong>NISA</strong></p>
<ul>
<li>投資で出た利益・配当に、ふつうは約20%かかる税金がかからない</li>
<li>払うお金（投資額）そのものは、所得控除にはならない</li>
</ul>
<p><strong>iDeCo</strong></p>
<ul>
<li>掛金の全額が所得控除になり、<strong>所得税と住民税が毎年減る</strong>（税率10%の人なら掛金の約20%）</li>
<li>運用益も非課税</li>
<li>
<p>受け取るときは、受け取り方によって税金がかかることがある</p>
</li>
<li>
<p><a href="https://note.com/fresh_snake1249/n/n4dc54593b929">iDeCoで税金はいくら減る？年末調整での書き方と早見表</a></p>
</li>
</ul>
<h2>3. 引き出せる時期のちがい</h2>
<ul>
<li><strong>NISA</strong>：いつでも売って引き出せる</li>
<li><strong>iDeCo</strong>：原則60歳まで引き出せない</li>
</ul>
<p>急にお金が必要になる可能性がある分は、iDeCo には向きません。</p>
<h2>4. いくらまで使える？</h2>
<p><strong>NISA（2024年からの新しい制度）</strong></p>
<ul>
<li>1年間に、つみたて投資枠 120万円＋成長投資枠 240万円＝最大360万円</li>
<li>一生で使える枠は1,800万円（売ると、翌年以降に枠が戻る）</li>
</ul>
<p><strong>iDeCo</strong></p>
<ul>
<li>働き方などで上限が違う</li>
<li>2026年12月分の掛金から上限が上がり、企業年金のない会社員は月6.2万円まで</li>
</ul>
<h2>5. 手数料などのちがい</h2>
<ul>
<li><strong>NISA</strong>：口座の管理手数料は、多くの金融機関で無料</li>
<li><strong>iDeCo</strong>：加入時と毎月、少額の手数料がかかる（金融機関によって違う）</li>
</ul>
<h2>6. 考え方の一例</h2>
<p>あくまで一般的な考え方の例です。</p>
<ul>
<li><strong>まずは生活費の数か月分の貯金</strong>をつくる（すぐ使えるお金）</li>
<li>いつでも引き出せる形で増やしたい分は NISA を検討</li>
<li>60歳まで使わないと決められる分で、毎年の税金も減らしたいなら iDeCo を検討</li>
</ul>
<p>自分がいくら貯金に回せるかは、手取りと固定費から考えるのが安心です。</p>

<h2>まとめ</h2>
<ul>
<li>NISA は利益が非課税でいつでも引き出せる。iDeCo は掛金が所得控除で毎年の税金が減るが、60歳まで引き出せない</li>
<li>NISA は年360万円・一生1,800万円まで。iDeCo は働き方で上限が違い、会社員は12月分から月6.2万円に</li>
<li>どちらも投資なので、元本が減ることもある</li>
<li>まずは生活費の貯金。そのうえで、使う時期に合わせて考える</li>
</ul>
