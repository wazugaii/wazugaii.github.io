<p>iDeCo（個人型確定拠出年金）は、払った掛金が<strong>全額、所得から引ける（所得控除）</strong>のが大きな特徴です。</p>
<ul>
<li>実際に、税金はいくら減るの？</li>
<li>年末調整では、どこに何を書けばいいの？</li>
<li>「12月から上限が上がる」って、今年の年末調整に関係ある？</li>
</ul>
<p>この記事では、この3つを整理します。</p>
<p>※ 2026年10月時点の情報です。細かい条件は、加入している金融機関（運営管理機関）や国税庁のサイトでご確認ください。iDeCoに入るべきか・掛金をいくらにするべきかは、人によって違います。この記事は税金の計算のしくみの説明です。</p>
<h2>1. 結論：掛金 ×（所得税率＋住民税10%）が減る</h2>
<p>iDeCoの掛金は、生命保険料控除のような上限がなく、<strong>払った額がまるごと所得控除</strong>になります。</p>
<p>減る税金の目安 ＝ <strong>1年の掛金 ×（所得税の税率 ＋ 住民税10%）</strong></p>
<p>たとえば、所得税の税率10%の人（年収400万〜600万円くらいの会社員）が月1万円払うと、</p>
<ul>
<li>1年の掛金 12万円 × 約20% ＝ <strong>約2.4万円</strong></li>
</ul>
<p>が、所得税と住民税から減ります。</p>
<h2>2. 早見表（1年で減る税金の目安）</h2>
<p>所得税は復興特別所得税（2.1%）を含めた目安、住民税は10%で計算しています。</p>
<p><strong>月1万円（年12万円）</strong></p>
<ul>
<li>税率5%の人：約1.8万円</li>
<li>税率10%の人：約2.4万円</li>
<li>税率20%の人：約3.7万円</li>
</ul>
<p><strong>月2.3万円（年27.6万円）… 企業年金のない会社員の、いまの上限</strong></p>
<ul>
<li>税率5%の人：約4.2万円</li>
<li>税率10%の人：約5.6万円</li>
<li>税率20%の人：約8.4万円</li>
</ul>
<p>注意：</p>
<ul>
<li>もともと払っている税金より多くは減りません。収入が少ない人や、ほかの控除が多い人は、早見表より少なくなります</li>
<li>控除が大きいと、所得税の税率が下の段に下がることがあります（そのときは早見表より少し少なくなります）</li>
</ul>
<p>自分の所得税・住民税がいくらかは、年収から計算できます。</p>

</ul>
<h2>3. 年末調整での書き方</h2>
<p>iDeCoの掛金を<strong>自分の口座から引き落としで払っている人</strong>は、年末調整で申告します。</p>
<ol>
<li>秋ごろに届く「<strong>小規模企業共済等掛金払込証明書</strong>」（国民年金基金連合会から届くハガキ）を用意する</li>
<li>会社の「保険料控除申告書」の「<strong>小規模企業共済等掛金控除</strong>」の欄に、「個人型確定拠出年金」の掛金の額を書く</li>
<li>証明書を添えて会社に出す</li>
</ol>
<p><strong>給料から天引きで払っている人</strong>（会社経由で払っている人）は、会社がすでに計算に入れているので、自分で書く必要はありません。</p>
<p>証明書をなくしたときは、国民年金基金連合会に再発行を頼めます。年末調整に間に合わなければ、翌年の確定申告でも控除を受けられます。</p>
<h2>4. 12月から上限が上がる：今年の年末調整には関係ない</h2>
<p>2026年12月から、iDeCoの掛金の上限が上がります。</p>
<ul>
<li>企業年金のない会社員：月2.3万円 → <strong>月6.2万円</strong></li>
<li>企業年金のある会社員：企業年金と合わせて月6.2万円まで</li>
<li>自営業など：月6.8万円 → 月7.5万円</li>
</ul>
<p>新しい上限が使えるのは、<strong>12月分の掛金（2027年1月に引き落とされる分）から</strong>です。</p>
<p>所得控除は「その年に払った掛金」で計算するので、<strong>新しい上限の分が税金に反映されるのは、2027年分（2027年の年末調整）から</strong>です。2026年の年末調整は、これまでどおりの掛金で計算します。</p>
<p>掛金を変えたい人は、金融機関での手続きが必要です。受付の締め切りは金融機関によって違い、10月末ごろに締め切るところもあるので、変えるつもりの人は早めに確認してください。</p>
<h2>5. 税金以外に知っておきたいこと</h2>
<p>所得控除はわかりやすいメリットですが、iDeCoには次のような特徴もあります。</p>
<ul>
<li><strong>原則60歳まで引き出せない</strong>（途中でお金が必要になっても使えない）</li>
<li>運用の結果によっては、払った額より減ることがある</li>
<li>受け取るときは、受け取り方によって税金がかかることがある</li>
<li>口座の管理手数料がかかる</li>
</ul>
<p>「税金が減るから」だけで決めず、生活費や貯金とのバランスで考えるのが安心です。</p>
