<p>一人暮らしをしていると、冬になって届く電気代の請求にびっくりすることがあります。</p>
<ul>
<li>一人暮らしの光熱費って、平均いくら？</li>
<li>冬はどれくらい増えるもの？</li>
<li>うちは高いの？安いの？</li>
</ul>
<p>この記事では、平均の数字と、冬に増える分を自分で計算する方法をまとめます。</p>
<h2>1. 一人暮らしの光熱・水道費の平均</h2>
<p>総務省の「家計調査（2025年）」をもとにした集計では、<strong>単身世帯の光熱・水道費は月平均 約13,300円</strong>です（電気・ガス・水道などの合計）。</p>
<p>地域によって差があり、寒い地域ほど高くなります。</p>
<ul>
<li>北海道・東北：月 約17,500円</li>
<li>関東：月 約12,200円</li>
</ul>
<p>これは1年の平均なので、<strong>冬は暖房の分だけ、この平均より高くなる</strong>のがふつうです。</p>
<h2>2. 冬に増えるのは、主に暖房の電気代</h2>
<p>冬の光熱費を押し上げるのは、ほとんどが暖房です。よく使う暖房を1か月（30日）使ったときの電気代の目安は、次のとおりです（電気の単価 31円/kWh で計算）。</p>
<ul>
<li>エアコン（6畳用）を1日8時間：約3,700円</li>
<li>電気ストーブ（強）を1日3時間：約2,200円</li>
<li>こたつ（中）を1日4時間：約740円</li>
<li>電気毛布を寝るときに7時間：約330円</li>
</ul>
<p>エアコンを毎日長く使うと、それだけで月3,000〜4,000円ほど増えます。これに、お湯をたくさん使う分のガス代・水道代が加わります。</p>

</ul>
<h2>3. 自分の暖房で計算するには</h2>
<p>家電をタップして、強さと使う時間を選ぶだけで、1か月の電気代がわかる無料ツールを作りました。消費電力を調べる必要はありません。</p>
<ul>
<li><a href="https://wazugaii.github.io/denki.html">電気代の計算ツール（家電を選ぶだけ）</a></li>
</ul>
<h2>4. 光熱費を下げるには</h2>
<ul>
<li><strong>エアコンの設定温度を1〜2度下げて、こたつや電気毛布を足す</strong>（体の近くを暖めるものは安い）</li>
<li><strong>寝るときはエアコンを切って、電気毛布にする</strong></li>
<li><strong>お風呂は続けて入る・追いだきを減らす</strong>（ガス代）</li>
<li><strong>電気・ガスの料金プランを見直す</strong>：使い方に合ったプランや会社に替えると、同じ使い方でも安くなることがあります</li>
</ul>
<p>光熱費は、家賃やスマホ代と同じく、毎月かかる「固定費」の一つです。まとめて見直すと、年に数万円変わることもあります。</p>
<ul>
<li><a href="https://wazugaii.github.io/koteihi.html">固定費の見直しシミュレーター（無料）</a></li>
<li><a href="https://note.com/fresh_snake1249/n/n11d45d3d8dfe">一人暮らしの家計簿・予算シート（Excel / Google スプレッドシート）</a>：光熱費の予算と実績を毎月比べられます</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>一人暮らしの光熱・水道費は、年平均で月 約13,300円（総務省の家計調査をもとにした集計）</li>
<li>冬は暖房の分だけ高くなる。エアコンを毎日8時間で月 約3,700円</li>
<li>体の近くを暖めるもの（こたつ・電気毛布）を組み合わせると下げやすい</li>
<li>自分の暖房は<a href="https://wazugaii.github.io/denki.html">電気代の計算ツール</a>で計算できる</li>
</ul>
<p>※ 電気代は目安です。実際の金額は、製品・部屋の広さ・断熱・地域・契約プランなどで変わります。</p>
