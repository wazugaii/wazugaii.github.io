<p>2024年に始まった新しいNISA。「つみたて投資枠」と「成長投資枠」の2つがあると聞いても、何がちがうのか分かりにくいですよね。</p>
<p>この記事では、2つの枠のちがいを、ポイントごとに整理します。</p>
<p>※ 2026年10月時点の一般的な制度の説明です。どの枠をどう使うべきか、何に投資するべきかは人によって違います。この記事は特定の商品やサービスをすすめるものではありません。</p>
<h2>1. ひとことで言うと</h2>
<ul>
<li><strong>つみたて投資枠</strong>：国が決めた基準を満たす投資信託を、<strong>コツコツ積み立てる</strong>ための枠</li>
<li><strong>成長投資枠</strong>：投資信託に加えて<strong>株式なども買える</strong>、自由度の高い枠</li>
</ul>
<p>どちらの枠も、<strong>利益や配当に税金がかからない</strong>のは同じです。2つの枠は同じ口座の中で<strong>両方使えます</strong>。</p>
<h2>2. 1年間に使える金額</h2>
<ul>
<li>つみたて投資枠：<strong>年120万円</strong>まで</li>
<li>成長投資枠：<strong>年240万円</strong>まで</li>
<li>合わせて<strong>年360万円</strong>まで</li>
</ul>
<h2>3. 一生で使える金額（生涯の上限）</h2>
<ul>
<li>2つの枠を合わせて<strong>1,800万円</strong>まで</li>
<li>そのうち成長投資枠で使えるのは<strong>1,200万円</strong>まで</li>
</ul>
<p>つみたて投資枠だけで1,800万円を使うこともできます。</p>
<h2>4. 買えるもののちがい</h2>
<p><strong>つみたて投資枠</strong></p>
<ul>
<li>長期の積立に向くとして、金融庁の基準を満たした投資信託など</li>
<li>手数料が低めの商品が中心</li>
</ul>
<p><strong>成長投資枠</strong></p>
<ul>
<li>上場している株式</li>
<li>投資信託（一部の、リスクが高いとされるものは対象外）</li>
<li>ETF・REIT など</li>
</ul>
<h2>5. 買い方のちがい</h2>
<ul>
<li><strong>つみたて投資枠</strong>：毎月など、決まった額を<strong>定期的に積み立てる</strong>買い方</li>
<li><strong>成長投資枠</strong>：積立でも、<strong>好きなときにまとめて買う</strong>のでもOK</li>
</ul>
<h2>6. 売ったら枠はどうなる？</h2>
<ul>
<li>売った分の<strong>買ったときの金額</strong>だけ、<strong>翌年に生涯の枠が復活</strong>する</li>
<li>ただし、<strong>年間の上限（年360万円）は復活しない</strong></li>
</ul>
<p>たとえば、100万円で買ったものを売ると、翌年以降、生涯の枠が100万円分戻ります。</p>
<h2>7. 非課税で持っていられる期間</h2>
<ul>
<li>2つの枠とも、<strong>期限なし</strong>（ずっと非課税で持っていられる）</li>
</ul>
<h2>8. 気をつけたいこと</h2>
<ul>
<li>投資なので、<strong>元本が減ることがある</strong></li>
<li>損が出ても、ほかの口座の利益と相殺（損益通算）はできない</li>
<li>NISA口座は、1人1つの金融機関でしか開けない（年単位で変更は可能）</li>
</ul>
