<p>10〜11月になると、保険会社から「生命保険料控除証明書」がハガキで届きます。</p>
<ul>
<li>これを年末調整に出すと、いくら戻るの？</li>
<li>新制度・旧制度って何がちがうの？</li>
<li>2026年から何か変わった？</li>
</ul>
<p>この記事では、生命保険料控除で<strong>実際に税金がいくら減るか</strong>を、計算式と早見表で整理します。</p>
<p>※ 2026年分（令和8年分）の内容です。細かい条件は国税庁のサイトや会社の案内でご確認ください。</p>
<h2>1. 結論：多くの人は年数千円〜2万円くらい</h2>
<p>生命保険料控除は、払った保険料がそのまま戻るわけではありません。<strong>「控除額 × 税率」の分だけ、所得税と住民税が減る</strong>しくみです。</p>
<p>目安（所得税の税率10%の人＝年収400万〜600万円くらいの会社員）：</p>
<ul>
<li>新制度の生命保険に年12万円（月1万円）払っている → 年 <strong>約6,900円</strong> 減る</li>
<li>生命保険・医療保険・個人年金をそれぞれ年8万円以上払っている → 年 <strong>約1.9万円</strong> 減る（ここが上限）</li>
</ul>
<h2>2. 控除は3つの枠に分かれている</h2>
<p>払っている保険は、次の3つの枠に分けて計算します。証明書のハガキに、どの枠かが書いてあります。</p>
<ul>
<li><strong>一般生命保険料</strong>：死亡保険・学資保険など</li>
<li><strong>介護医療保険料</strong>：医療保険・がん保険など</li>
<li><strong>個人年金保険料</strong>：税制適格の個人年金保険</li>
</ul>
<p>さらに、<strong>2011年までに契約した保険は「旧制度」、2012年以降は「新制度」</strong>で、計算式が違います。</p>
<h2>3. 新制度（2012年以降の契約）の計算式</h2>
<p>1つの枠ごとに、年間の保険料から控除額を出します。</p>
<p><strong>所得税（上限4万円）</strong></p>
<ul>
<li>2万円以下 → 全額</li>
<li>2万円超〜4万円 → 保険料 × 1/2 ＋ 1万円</li>
<li>4万円超〜8万円 → 保険料 × 1/4 ＋ 2万円</li>
<li>8万円超 → 一律 4万円</li>
</ul>
<p><strong>住民税（上限2.8万円）</strong></p>
<ul>
<li>1.2万円以下 → 全額</li>
<li>1.2万円超〜3.2万円 → 保険料 × 1/2 ＋ 6,000円</li>
<li>3.2万円超〜5.6万円 → 保険料 × 1/4 ＋ 1.4万円</li>
<li>5.6万円超 → 一律 2.8万円</li>
</ul>
<p>3つの枠の合計は、<strong>所得税で最大12万円、住民税で最大7万円</strong>です。</p>
<h2>4. 2026年の変更：23歳未満の子がいると「一般」の上限が6万円に</h2>
<p>2026年分は、<strong>12月31日時点で23歳未満の扶養親族（配偶者は除く）がいる人</strong>は、新制度の<strong>一般生命保険料</strong>の所得税の上限が、4万円から<strong>6万円</strong>に上がります。</p>
<ul>
<li>3万円以下 → 全額</li>
<li>3万円超〜6万円 → 保険料 × 1/2 ＋ 1.5万円</li>
<li>6万円超〜12万円 → 保険料 × 1/4 ＋ 3万円</li>
<li>12万円超 → 一律 6万円</li>
</ul>
<p>注意点：</p>
<ul>
<li>上がるのは<strong>所得税の「一般」の枠だけ</strong>。介護医療・個人年金の枠、住民税は変わりません</li>
<li>3つの枠の合計の上限（所得税12万円）は<strong>そのまま</strong>。すでに12万円に届いている人は増えません</li>
<li>年末調整の「保険料控除申告書」に、<strong>23歳未満の扶養親族の有無</strong>を書く欄があります。チェックを忘れると上限が4万円のまま計算されます</li>
</ul>
<h2>5. 旧制度（2011年までの契約）の計算式</h2>
<p><strong>所得税（1枠の上限5万円）</strong></p>
<ul>
<li>2.5万円以下 → 全額</li>
<li>2.5万円超〜5万円 → 保険料 × 1/2 ＋ 1.25万円</li>
<li>5万円超〜10万円 → 保険料 × 1/4 ＋ 2.5万円</li>
<li>10万円超 → 一律 5万円</li>
</ul>
<p><strong>住民税（1枠の上限3.5万円）</strong></p>
<ul>
<li>1.5万円以下 → 全額</li>
<li>1.5万円超〜4万円 → 保険料 × 1/2 ＋ 7,500円</li>
<li>4万円超〜7万円 → 保険料 × 1/4 ＋ 1.75万円</li>
<li>7万円超 → 一律 3.5万円</li>
</ul>
<p>新制度と旧制度の両方がある枠は、「旧だけで計算」「新だけで計算」「両方を足して計算（上限4万円）」のうち、いちばん大きいものを選べます。</p>
<h2>6. 減る税金の早見表</h2>
<p><strong>新制度の一般生命保険だけを、年12万円（月1万円）払っている人</strong>（所得税の控除4万円・住民税の控除2.8万円）</p>
<ul>
<li>税率5%の人：約4,800円（所得税 約2,000円＋住民税 2,800円）</li>
<li>税率10%の人：約6,900円（所得税 約4,100円＋住民税 2,800円）</li>
<li>税率20%の人：約1.1万円（所得税 約8,200円＋住民税 2,800円）</li>
</ul>
<p>23歳未満の子がいる人は、所得税の控除が6万円になるので、税率10%なら<strong>約8,900円</strong>（約2,000円アップ）です。</p>
<p><strong>3つの枠すべてで上限まで払っている人</strong>（所得税12万円・住民税7万円）</p>
<ul>
<li>税率5%の人：約1.3万円</li>
<li>税率10%の人：約1.9万円</li>
<li>税率20%の人：約3.2万円</li>
</ul>
<p>※ 所得税は復興特別所得税（2.1%）を含めた目安。住民税は10%で計算しています。</p>

<h2>7. 年末調整での出し方</h2>
<ol>
<li>保険会社から届いた<strong>控除証明書</strong>（ハガキ）を用意する</li>
<li>会社の「保険料控除申告書」に、保険会社名・保険の種類・<strong>年間の保険料（証明書の「申告額」）</strong>を書く</li>
<li>新制度・旧制度を区別して、枠ごとに計算する（会社のシステムなら自動計算のことも多いです）</li>
<li>23歳未満の扶養親族がいる人は、その欄にチェックと記入</li>
<li>証明書を添えて会社に出す</li>
</ol>
<p><strong>証明書をなくしたとき</strong>は、保険会社のサイトやコールセンターで再発行できます。年末調整に間に合わなければ、翌年の確定申告で控除を受けることもできます。</p>
