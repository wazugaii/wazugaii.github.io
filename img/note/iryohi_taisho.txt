<p>医療費控除は、1年間に払った医療費が多いときに税金が戻る制度です。ただ、「これは対象になるの？」と迷うものも多いですよね。</p>
<p>この記事では、よくあるものを<strong>対象になる・ならない</strong>に分けて整理します。</p>
<p>※ 一般的な取り扱いの整理です。個別の判断は、国税庁のサイトや税務署でご確認ください。</p>
<h2>1. 基本の考え方</h2>
<p>医療費控除の対象になるのは、<strong>病気やけがの「治療」のための費用</strong>です。</p>
<ul>
<li>治療のため → 対象になることが多い</li>
<li>予防・健康づくり・美容のため → 対象にならないことが多い</li>
</ul>
<p>この「治療のためか」が判断の基本です。</p>
<h2>2. 対象になるもの</h2>
<p><strong>病院・薬</strong></p>
<ul>
<li>病院・診療所の診察代・治療代・入院費</li>
<li>医師の処方による薬代</li>
<li>治療のために買った<strong>市販薬</strong>（かぜ薬・胃腸薬・湿布など）</li>
<li>入院中の食事代（病院が出すもの）</li>
</ul>
<p><strong>歯医者</strong></p>
<ul>
<li>虫歯・歯周病の治療</li>
<li>治療目的の<strong>インプラント・入れ歯・金歯など</strong>（一般的な材料・費用の範囲）</li>
<li>子どもの<strong>歯列矯正</strong>（成長を妨げないためなど、治療が目的のもの）</li>
</ul>
<p><strong>交通費</strong></p>
<ul>
<li>通院のための<strong>電車・バス代</strong>（領収書がなくても、記録があればOK）</li>
<li>歩くのが難しいときや緊急時の<strong>タクシー代</strong></li>
</ul>
<p><strong>そのほか</strong></p>
<ul>
<li>出産費用・妊婦健診（出産育児一時金などで補てんされた分は差し引く）</li>
<li>不妊治療</li>
<li>治療目的の<strong>はり・きゅう・マッサージ</strong>（国家資格を持つ人が行うもの）</li>
<li>介護保険の一部のサービス（自己負担分）</li>
<li>健康診断で病気が見つかり、そのまま治療した場合の<strong>健康診断の費用</strong></li>
</ul>
<h2>3. 対象にならないもの</h2>
<ul>
<li>健康診断・人間ドック（異常がなかった場合）</li>
<li>予防接種</li>
<li>健康のためのビタミン剤・サプリメント</li>
<li>美容整形・ホワイトニング・美容目的の歯列矯正</li>
<li>一般的な視力矯正の<strong>メガネ・コンタクトレンズ</strong></li>
<li>自家用車で通院したときの<strong>ガソリン代・駐車場代</strong></li>
<li>自分の希望で選んだ入院中の<strong>個室の差額ベッド代</strong></li>
<li>疲れをとるためのマッサージ</li>
</ul>
<h2>4. 迷いやすいもの</h2>
<p><strong>市販薬</strong></p>
<ul>
<li>治療のためなら対象。予防や健康づくりのためなら対象外</li>
<li>「セルフメディケーション税制」（対象の市販薬を年1.2万円以上買った人向けの別の制度）を選ぶこともできる。ただし医療費控除との<strong>併用はできない</strong></li>
</ul>
<p><strong>メガネ・コンタクト</strong></p>
<ul>
<li>一般的な近視・遠視は対象外</li>
<li>医師の指示による、病気の治療のためのもの（白内障の手術後など）は対象になることがある</li>
</ul>
<p><strong>保険で戻ってきたお金</strong></p>
<ul>
<li>生命保険の入院給付金や、高額療養費で戻ってきたお金は、<strong>払った医療費から差し引く</strong></li>
</ul>
<h2>5. いくら戻るか</h2>
<p>医療費控除は、ざっくり言うと</p>
<p><strong>（1年の医療費 − 保険などで戻った分 − 10万円）× 税率</strong></p>
<p>が戻ってくる目安です。所得が200万円未満の人は、10万円ではなく「所得の5%」を引きます。</p>
<ul>
<li><a href="https://wazugaii.github.io/iryohi.html">医療費控除でいくら戻るか計算（無料）</a></li>
<li><a href="https://note.com/fresh_snake1249/n/n459f3fc5d4c6">医療費控除、10万円いかなくても使える？「所得の5%」ルール</a></li>
</ul>
<p>医療費控除は年末調整ではできず、<strong>確定申告</strong>が必要です。1年分の領収書や医療費通知をまとめておくと、2〜3月の申告がラクになります。</p>
<h2>まとめ</h2>
<ul>
<li>判断の基本は「治療のためか」</li>
<li>治療目的の市販薬・通院の電車代・治療の歯科治療は対象</li>
<li>健康診断（異常なし）・予防接種・サプリ・美容・一般のメガネ・ガソリン代は対象外</li>
<li>保険で戻ったお金は差し引く</li>
<li>申告は確定申告で</li>
</ul>
